KITABOG NATIONAL HIGH SCHOOL WEBSITE - CUSTOMIZED VERSION

Included:
- Official school logo (school-logo.jpg)
- School address and principal
- Supplied DepEd vision and mission
- Phone contact number
- Facebook page name
- Responsive layout for phones and computers

PREVIEW
Open index.html in a web browser.

PUBLISH FREE WITH GITHUB PAGES
1. Sign in to GitHub and create a public repository (example: kitabog-nhs-website).
2. Upload index.html, styles.css, script.js, and school-logo.jpg.
3. Go to repository Settings > Pages.
4. Select Deploy from a branch, choose main and /(root), then Save.
5. GitHub will provide a free github.io address.

A free hosting plan is subject to the provider's current terms and can change; a custom domain usually costs money. No provider can guarantee lifetime free service.

TO CONFIRM BEFORE PUBLISHING
- Review the content and ensure school authorization before publishing.
- Obtain appropriate permission before posting learner photos or personal information.
